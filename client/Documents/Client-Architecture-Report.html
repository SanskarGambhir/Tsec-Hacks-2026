🔄 Application Flow

1. 📄 index.html
Entry HTML file served by Vite
Contains: <div id="root"></div> + script to main.jsx
⬇️
2. 🚀 main.jsx - React Entry Point
• Imports React and ReactDOM
• Imports global styles (index.css)
• Renders App inside StrictMode
• Mounts to #root element
⬇️
3. 🔀 App.jsx - Router Configuration
• Sets up BrowserRouter
• Defines Routes for all pages
• Maps URLs to page components
⬇️
4. 📄 Page Components (Login, SignUp, Homepage)
• Render UI with Tailwind CSS
• Manage local state with useState
• Call API functions from /api folder
• Navigate using useNavigate hook
⬇️
5. 📡 API Layer (api/axios.js + api/auth.js)
• Axios instance with baseURL: localhost:8000
• withCredentials: true (sends cookies)
• Auth functions: registerUser, loginUser
⬇️
6. 🖥️ Backend Server
• Receives request at /api/v1/auth/*
• Processes and returns JSON response
• Sets cookies (accessToken, refreshToken)

📡 API Layer

Axios Configuration (api/axios.js)

import axios from "axios";

const api = axios.create({
  baseURL: "http://localhost:8000",  // Backend server URL
  withCredentials: true,              // Send cookies with requests
});

export default api;

Key Settings:

  • baseURL: Points to Express server on port 8000
  • withCredentials: Essential for sending/receiving cookies (JWT tokens)

Auth API Functions (api/auth.js)

import api from "./axios.js";

export const registerUser = (userData) => {
  return api.post("/api/v1/auth/register", userData);
};
// userData: { email, username, password }

export const loginUser = (credentials) => {
  return api.post("/api/v1/auth/login", credentials);

🛠️ Utility Functions

cn() - Class Name Utility (lib/utils.ts)

import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

// Usage:
cn("px-4 py-2", isActive && "bg-primary", className)
// Merges classes and resolves Tailwind conflicts

How it works:

  • clsx: Conditionally joins classNames (handles falsy values)
  • twMerge: Merges Tailwind classes without conflicts (e.g., "px-2 px-4" → "px-4")
